# Weather Forecast App

A responsive weather application built with React and Tailwind CSS that provides real-time weather information, hourly forecasts, and daily forecasts using WeatherAPI.

I created this project to improve my understanding of React, API integration, data manipulation, component composition, and responsive web design.

## Current Features

- Current temperature and weather conditions
- Hourly weather forecast
- Daily weather forecast
- Feels-like temperature
- Humidity levels
- Wind speed
- Precipitation levels
- Dynamic weather icons
- Date and time formatting
- Responsive layout for mobile and desktop devices
- Scrollable forecast containers

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- HTML5
- CSS3
- Vite
- WeatherAPI
